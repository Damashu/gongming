# 「共鸣」—— 一个不帮你找对象，帮你懂自己的产品

> 项目讲述 · 对外 / 演讲版（通俗、可读、可直接照着讲）

## 开场：先讲清楚我们不做的事

我要做的，不是一个「更聪明的交友软件」，也不是又一个 MBTI、星座、心理测试。

市面上帮你「找对象」的软件已经够多了——左滑右滑、看照片、聊两句。它们做得够多，也够烂了。不是技术烂，是它们压根没解决真问题。

## 中国婚恋的真痛点，不是「找不到人」

你去问一个用过婚恋软件的人，他的烦归结起来就四个字：**预期错位**。

- 他不知道自己要什么，只知道「感觉不对」；
- 他不了解对方，只能靠照片和几句资料瞎猜；
- 他在关系里反复踩同一个坑，却不知道坑在哪；
- 最要命的，他羞于用婚恋软件——「用这个，是不是说明我没人要？」

有意思的是，你看看小黑盒——一个游戏社区，反而能延伸出恋爱故事、纯爱分享、分手复盘。人们不是不聊感情，他们只是**不想在一个明码标价、像挑货一样挑人的地方聊感情**。

所以痛点从来不是「缺一个匹配算法」，而是：**人在婚恋这件事上，看不清自己，也看不清别人。**

## 我们想做的事：把最大的流量，变成最稀缺的价值

中国互联网上最大的流量是什么？人性八卦、婚恋撕扯、真人秀争议。

「妈宝男」「凤凰男」「捞女」「普信男」——这些词是谁喂出来的？是小红书、是微博，用十年时间养出来的流量密码。

但它们只做了两件事：**给你情绪，或者给你配对。** 中间那一层——**「从撕扯到理解」**——没人做。

我们站的位置，就是这个空缺。

「共鸣」要做的，一句话：**帮一个人看懂自己、看懂别人、看懂关系。**

## 它长什么样：三层

**第一层，皮——匹配。** 社区 + 交友 + 动态偏好。这一层是入口、是留存。探探、陌陌、珍爱网都停在这一层。我们要有，但这不是我们的野心。

**第二层，骨——关系认知。** 我们的哲学根基是一句话：**人是社会关系的总和。** 你成为今天这个样子，是家庭、经济、社会经历一点点堆出来的。所以我们不给人贴标签——不问「你是不是自卑型、是不是普信男」，我们问「**他为什么成了这样**」。

这就是我们和 MBTI、星座、一切心理测试最根本的区别：**它们给你一个静态标签，我们给你一段因果故事。**

我们要帮每个人回答三件事：
1. 我是什么样的人，为什么是这样；
2. 别人是什么样的人，为什么是那样；
3. 我们俩合不合适，会在哪儿出矛盾。

**第三层，魂——人性百科 + 关系观察社区。** 这是让这个产品「经久不衰」的地方。

人性八卦这件事，永远不会过时。孙杨、豆豆、妈宝男——这类事件代代重演、永不枯竭。我们要把每一种「人」做成一个词条：他为什么变成这样、有什么典型故事、会有什么争议、对应哪套问卷。

**八卦负责把人引进来，认知负责把人留下来，匹配负责把人转化。**

## 为什么它立得住：一个会自我强化的闭环

社会事件 → 大众讨论 → 拆解成因 → 变成问卷和类型 → 帮人认识自己 → 引导匹配 → 真实关系反馈 → 反哺案例库。

**内容喂数据，数据养内容。**

这才是真正的护城河。因为问卷、标签、算法，别人都能抄；但滚了三年、经过用户授权沉淀下来的**真实案例库**和**用户信任**，抄不走。

## 我们必须守住的一条线

这里有个坎，必须一开始就想清楚，而不是等出事再补：

**内容要刺激，认知要克制——这俩会打架。**

「妈宝男」三个字能带来十万阅读，可它恰恰是我们认知系统要拆掉的东西。八卦越贴标签越传播，认知越拒绝标签越可信。

我们不做第二个「男女对立战场」。我们要做的，是让人看完一个案例之后，不是去骂「这种人真恶心」，而是停下来想一想：**「我是不是也有点这样？」「我为什么会喜欢这种人？」**

这是「人性百科」和「撕逼广场」的分界线，也是这个产品能不能立住的命门。

## 最后，一句话

交友软件卖的是「配对」——那是单次交易，做完就散。

我们卖的是「理解」——一个终身、会自我强化的需求。

前者的天花板是珍爱网。后者的天花板，我们还没见过。

这就是「共鸣」。
